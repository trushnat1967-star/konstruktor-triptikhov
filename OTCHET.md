# Отчёт о выполненной работе

**Наименование проекта:** Конструктор-Триптих
**Дата:** 02.10.2026
**Статус:** Завершено

## Цель задания

Разработка инструмента для формирования триптихов — композиций из трёх взаимосвязанных частей с общим названием, темой, текстовым наполнением, изображениями и единым оформлением, включая предпросмотр и выгрузку результата одним файлом-изображением.

## Перечень выполненных действий

1. **Создан интерфейс конструктора:**
   - шапка с действиями («Создать новый триптих», «Открыть превью», «Скачать PNG»), индикатором автосохранения и прогрессом заполнения;
   - двухколоночная рабочая зона: пошаговый редактор слева, живое превью справа.
2. **Реализован пошаговый редактор (3 шага):**
   - Шаг 1 «Основа» — название триптиха (до 80 символов) и общая тема (до 220 символов);
   - Шаг 2 «Части» — для левой, центральной и правой частей: заголовок (до 60), короткий текст (до 280), изображение; переключатель I / II / III, кнопки навигации между частями, индикаторы готовности;
   - Шаг 3 «Оформление» — 6 цветовых палитр, 6 фонов, 6 шрифтов; применяется ко всем частям одновременно.
3. **Реализована загрузка изображений:** по клику и drag-and-drop, проверка типа файла, автоматическое масштабирование до 1200 px по длинной стороне, упаковка в dataURL (JPEG/PNG), замена и удаление.
4. **Реализовано живое превью:** компонент `TriptychView` в режиме `live`, мгновенная реактивная отрисовка всех изменений; адаптивная вёрстка (на узких экранах панели выстраиваются вертикально для читаемости).
5. **Реализовано модальное превью:** окно «Открыть превью» с триптихом целиком на любом размере экрана, доступно из шапки и панели превью.
6. **Реализована отдельная экспортная версия:** компонент `TriptychView` в режиме `poster` — фиксированный горизонтальный холст 1600 px, жёсткая сетка 3 равные колонки (инлайн-стили, вне зависимости от брейкпоинтов), панели строго слева направо, изображения 16/10.
7. **Реализована цепочка экспорта в PNG:** рендер подготовленного DOM-узла постера (не скриншот экрана) → нативный диалог «Сохранить как» (File System Access API) → запасной вариант автоматической загрузки через объектный URL → запасной вариант ручного сохранения (модальное окно с готовым изображением, инструкцией и кнопкой повторного скачивания); отображение фактических размеров файла и пометки «альбомная».
8. **Реализовано автосохранение:** дебаунс-запись проекта в localStorage, восстановление при повторном открытии, индикатор «Сохранено · время», обработка переполнения квоты; при первом визите подставляется демонстрационный проект.
9. **Реализован сценарий «Новый триптих»:** при наличии заполненных данных — модальный диалог «Создать новый / Отмена», отмена сохраняет данные без изменений; сброс состояния, возврат на шаг 1.
10. **Реализованы вспомогательные элементы:** тосты уведомлений, счётчики символов, стартовый демо-контент, адаптив под десктоп / планшет / смартфон.

## Полученный результат

Итоговый продукт — одностраничное веб-приложение «Конструктор-Триптих».

Возможности:
- задание названия и общей темы триптиха;
- наполнение трёх частей (заголовок, текст, изображение каждой);
- выбор палитры, фона и шрифта с применением ко всем частям;
- живое адаптивное превью + полноэкранное модальное превью;
- автосохранение в браузере и восстановление сессии;
- выгрузка результата одним горизонтальным PNG-файлом (1600 px × 2 pixelRatio): все три панели, название, тема и оформление.

## Использованные средства/подходы

- **Стек:** React 19, TypeScript, Vite 7, Tailwind CSS 4, сборка в единый HTML (vite-plugin-singlefile).
- **Архитектура:** разделение экранного (`live`) и экспортного (`poster`) представлений; цепочка «данные → редактор → живой предпросмотр → экспортная версия → PNG → Сохранить как».
- **Экспорт:** библиотека html-to-image (рендер DOM-узла), File System Access API (`showSaveFilePicker`), объектный URL как fallback.
- **Хранение:** localStorage с нормализацией и валидацией структуры проекта.
- **Совместимость экспорта:** фоны только на CSS-градиентах (корректно запекаются в PNG), ожидание `document.fonts.ready` и догрузки изображений перед снимком.
- **Шрифты (Google Fonts):** Playfair Display, Cormorant Garamond, Manrope, Unbounded, Marck Script, JetBrains Mono.
- **Иконки:** Lucide.
